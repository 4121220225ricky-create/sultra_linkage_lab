SULTRA LINKAGE LAB — FORKESTRA BI SULAWESI TENGGARA 2026
Versi final publik · 14 Agustus 2026

ISI PAKET
- index.html              dashboard interaktif
- database.json           basis data terstruktur JSON UTF-8
- assets/                 salinan build JavaScript dan CSS untuk kompatibilitas
- visuals/                logo serta delapan latar 3D per tab
- README.txt              petunjuk dan atribusi

CARA MEMBUKA
1. Ekstrak seluruh isi ZIP ke satu folder.
2. Buka index.html dengan peramban modern (Chrome, Edge, Firefox, atau Safari).
3. Pertahankan folder visuals/ di samping index.html. JavaScript dan CSS utama
   sudah tertanam di dalam index.html agar dapat dibuka langsung secara lokal.

CAKUPAN
Dashboard memuat ringkasan paper final; analisis linkage 52 industri; SPA;
dampak IRIO 34 provinsi; simulator rewiring; LQ, DLQ, SSA dan Tipologi
Klassen untuk 17 kabupaten/kota; kapasitas IMK dan tenaga kerja; matriks
integrasi pemangku kepentingan; metodologi; serta metadata sumber.

CATATAN INTERPRETASI
Hasil IO/IRIO, SPA, dan rewiring adalah keluaran model atau analisis
sensitivitas. Angka tersebut bukan estimasi dampak kausal bersih atau janji
realisasi. Status angka observasi dicantumkan pada dashboard dan database.
